# Toy ToDo 仕様書

## 1. 概要
Toy ToDo は、シンプルなタスク管理アプリケーションです。REST APIを通じてタスクの作成、取得、更新、削除が可能です。

## 2. ユースケース

### 2.1 タスク作成
- ユーザーはタスクのタイトルを入力して新しいタスクを作成できる
- 作成されたタスクは未完了状態で保存される

### 2.2 タスク一覧取得
- ユーザーは登録されているすべてのタスクを一覧で取得できる
- 各タスクには、ID、タイトル、完了状態、作成日時の情報が含まれる
- タスクの完了状態でフィルタすることができる

### 2.3 タスク完了状態の更新
- ユーザーはタスクの完了状態（完了/未完了）を更新できる
- 更新された状態はデータベースに永続化され、次回のアクセス時も保持される

### 2.4 タスク削除
- ユーザーは不要になったタスクをシステムから削除できる

## 3. 技術仕様

API仕様の詳細については、[openapi.yaml](/spec/openapi.yaml)ファイルを参照してください。このファイルにはすべてのエンドポイント、リクエスト/レスポンスの形式、ステータスコードなどの詳細が記載されています。
